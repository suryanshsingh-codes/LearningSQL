# 📖 About This Repository

Welcome to my **Learning SQL** repository.

This repository documents my journey of learning **SQL** from fundamentals to advanced concepts through hands-on practice and real-world datasets.

The primary focus is not only writing SQL queries but understanding how databases work, how information is stored, retrieved, managed, and optimized for modern Data Analytics, Data Science, and Machine Learning workflows.

Every script represents practical implementation instead of only theoretical concepts.
